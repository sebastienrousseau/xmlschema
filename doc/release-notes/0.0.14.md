# xmlschema 0.0.14

Release preparation dated 2026-11-01. This file does not announce a
publication or authorize a tag.

## Highlights ⭐️

* **`oxml 0.0.13` alignment**: Update the publishable package, conformance helper, and fuzz harness to `oxml = "=0.0.13"` and refresh the root and fuzz `Cargo.lock` files.
* **Workflow action update**: Advance `taiki-e/install-action` to `v2.88.0` (`86f7a0ffb25f40114606501a311ebcfaf882ea32`) in both `ci.yml` and `release.yml`.

## Upgrade notes

Rust 1.89.0 or newer is required. The package depends on `oxml = "=0.0.13"`.
Unpublished fuzz and conformance harnesses remain non-publishable.

## Verification and release status

The fuzz policy permits NCSA only for libfuzzer-sys 0.4.13; it does not
extend the runtime license allowlist. Security CI checks both graphs.
Release tags must be annotated, signed by a key in
`.github/allowed_signers`, and use the subject `xmlschema v0.0.14`.
The release workflow uses crates.io Trusted Publishing without a stored
token fallback.
